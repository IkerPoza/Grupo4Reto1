# AERGIBIDE SL

Aplicación web de preguntas y respuestas desarrollada para facilitar la comunicación y el intercambio de conocimientos entre los trabajadores de AERGIBIDE SL, empresa del sector aeronáutico ubicada en Vitoria-Gasteiz.

## Descripción del proyecto

La plataforma permite a los trabajadores compartir dudas, consultar respuestas y acceder a recursos útiles relacionados con su actividad profesional. Su objetivo es centralizar el conocimiento y facilitar la colaboración entre los usuarios.

## Funcionalidades principales

- **Gestión de usuarios:** registro, inicio de sesión y edición del perfil.
- **Preguntas y respuestas:** publicación de preguntas, consulta de detalles y participación mediante respuestas.
- **Interacción:** votación de respuestas y guardado de contenido favorito.
- **Gestión de contenido:** consulta y organización de preguntas por categorías.
- **Documentación:** publicación y consulta de documentos compartidos.
- **Administración:** gestión de usuarios y funcionalidades según los permisos asignados.

## Tecnologías utilizadas

- **Frontend:** HTML5, CSS3 y JavaScript.
- **Backend:** PHP.
- **Base de datos:** MySQL.
- **Entorno de desarrollo:** Laragon.
- **Control de versiones:** Git y GitHub.
